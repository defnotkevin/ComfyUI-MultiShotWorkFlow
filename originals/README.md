# Original export with setup notes

`ComfyUIMultiShotWorkflowCoffeeExample.json` in this directory retains the generation nodes, settings and connections supplied by the author. Three Markdown notes were added on October 30, 2026 to explain account setup, credits and the coffee media assignments. The JSON is therefore no longer a byte for byte copy of the original upload.

Its media filenames still refer to the author's existing workspace, its three image Director prompts are empty, and the overhead batch includes an empty slot. The notes direct users to the prepared workflow rather than treating this archived graph as ready to run.

Use the JSON at the repository root for the documented coffee example. See [the change list](../docs/WORKFLOW.md#changes-from-the-supplied-export).
